🧪 GitHub 로그인 테스트 헬퍼

📌 사용 방법:
1. GitHub 자동 로그인 문제가 있을 때 이 페이지를 사용하세요
2. "완전 클리어" 버튼으로 모든 세션을 제거할 수 있습니다
3. 테스트 후 새 시크릿 창에서 로그인을 테스트하세요
