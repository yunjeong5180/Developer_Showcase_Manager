## 📝 테스트 진행 방법

1. **단위 테스트**: 각 함수와 컴포넌트를 개별적으로 테스트
2. **통합 테스트**: 여러 컴포넌트와 서비스 간의 상호작용 테스트
3. **E2E 테스트**: 실제 사용자 시나리오를 따라 전체 플로우 테스트
4. **회귀 테스트**: 수정 후 기존 기능이 여전히 작동하는지 확인

## 🐛 이슈 추적

테스트 중 발견된 이슈는 다음 형식으로 기록:

```markdown
### [이슈 #번호] 이슈 제목
- **테스트 항목**: 어떤 테스트에서 발견되었는지
- **재현 방법**: 이슈를 재현하는 단계
- **예상 결과**: 정상적인 경우 예상되는 결과
- **실제 결과**: 실제로 발생한 결과
- **우선순위**: Critical/High/Medium/Low
- **상태**: Open/In Progress/Resolved
```
